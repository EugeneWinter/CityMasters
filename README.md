# Курсовая работа: Экономический симулятор «Городские Мастера»

Учебный проект 2D градостроительной стратегии, разработанный в рамках курсовой работы по дисциплине «Разработка компьютерных игр».

---

## 🎮 Описание игры

**«Городские Мастера»** (Вариант 8-9) — казуальная экономическая стратегия с акцентом на планирование. Игрок выступает в роли мэра поселения и должен превратить его в процветающий мегаполис, грамотно распределяя ресурсы и развивая городскую инфраструктуру.

### 🌟 Основные особенности и механики:
- **Строительство и демонтаж на сетке:** размещение зданий и дорог на островных картах (`GridManager`, `BuildingPlacer`).
- **Авто-тайлинг дорожной сети:** автоматическое сопряжение поворотов и перекрёстков на основе 4-битных масок (`AutoTileRoad`).
- **Экономика и ресурсы:**
  - *Бюджет ($):* налоговые поступления от бизнеса и жителей.
  - *Население:* рост при постройке жилых домов.
  - *Счастье (%):* балансировка между экологией (парки) и промышленностью (заводы).
  - *Электроэнергия:* потребление и генерация энергии зданиями.
- **Инфраструктура:** здания требуют подключения к дорожной сети для полноценной работы.
- **Динамические диалоги жителей:** контекстные реплики горожан, реагирующие на отсутствие дорог, дефицит энергии или качество жизни.
- **2 Игровых Уровня:**
  - *Уровень 1 «Поселение»:* стартовый капитал $1000, цель — 30 жителей и 50% счастья.
  - *Уровень 2 «Мегаполис»:* стартовый капитал $1500, цель — 80 жителей и 70% счастья.
- **Условия конца игры:**
  - *Победа:* достижение целевых показателей уровня с удержанием результата.
  - *Поражение:* банкротство (долг ниже -$500) или истечение лимита времени.

## 📂 Структура проекта

```
Assets/
├── Prefabs/
│   └── City/                    # Префабы зданий (House, Shop, Factory, Park)
├── Resources/                   # ScriptableObjects данных зданий (BuildingData)
├── Scripts/
│   ├── GameManager.cs           # Состояние игры, скорость времени, условия победы/поражения
│   ├── ResourceManager.cs       # Экономика, баланс ресурсов, налоги и расходы
│   ├── GridManager.cs           # Двумерная сетка тайлов, типы ландшафта
│   ├── BuildingPlacer.cs        # Строительство, предпросмотр ("призрак"), демонтаж
│   ├── AutoTileRoad.cs          # Логика и авто-тайлинг дорожной сети
│   ├── Building.cs              # Логика конкретного здания, привязка к дорогам
│   ├── BuildingData.cs          # ScriptableObject данных параметров зданий
│   ├── ResidentDialogue.cs      # Контекстные диалоги и обращения горожан
│   ├── UIManager.cs             # Реактивный UI, HUD ресурсов, диалоги, окна
│   └── CameraController.cs      # Панорамирование, зум и ограничение камеры
├── Sprites/                     # 2D Тайлы и спрайты интерфейса
└── Scenes/
    ├── MainMenu.unity           # Главное меню
    ├── CityLevel1.unity         # Уровень 1: Поселение
    └── CityLevel2.unity         # Уровень 2: Мегаполис
```

## 🛠 Технологический стек

- **Движок:** Unity 2022.3.62f3 LTS (2D Core)
- **Язык программирования:** C#
- **UI система:** Unity UI + TextMeshPro (TMP)
- **Архитектура:** Singleton, Event-Driven Architecture, ScriptableObject

## 🚀 Инструкция по запуску

1. Склонируйте или скачайте данный репозиторий.
2. Откройте проект в **Unity 2022.3 LTS**.
3. Перейдите в папку `Assets/Scenes/` и откройте сцену `MainMenu.unity` (или `CityLevel1.unity`).
4. Нажмите кнопку **Play** в редакторе Unity.
